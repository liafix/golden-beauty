# Build plan

## Cieľ

Vytvoriť prémiový mobile-first demo web, ktorý okamžite sprístupní kontakt, lokalitu a jednoduchú požiadavku na termín bez vymýšľania služieb alebo cien.

## Vizuálny smer

- editorial beauty, nie SaaS landing page
- warm ivory / ink / restrained gold
- serif display + system sans
- minimum dekorácie, veľa priestoru
- žiadne cudzie fotografie, logá ani social-media assety

## Funkčnosť

- funkčné anchors a tel: CTA
- map link
- 3-krokový demo appointment-request flow
- explicitné upozornenie, že nič sa neodosiela
- noindex,nofollow
- keyboard focus, semantic labels, reduced motion
