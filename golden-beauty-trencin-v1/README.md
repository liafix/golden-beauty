# GOLDEN beauty Trenčín — Demo v1

Neoficiálny prezentačný web vytvorený v DCZ Lead Demo Factory V2.0.

## Spustenie

Statický web bez build kroku. Otvorte `index.html` alebo spustite lokálny server:

```bash
python -m http.server 8080
```

## Dôležité

- `noindex,nofollow` je zapnuté v HTML aj vo Vercel headers.
- Formulár je iba demo flow a nič neodosiela ani neukladá.
- Použité sú iba CSS/typografické vizuály; neboli prevzaté verejné fotografie zo sociálnych sietí.
- Neoverené ceny, služby, mená, otváracie hodiny ani sociálne profily nie sú na stránke uvedené.
